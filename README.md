## 🌌 What is AXT DIMENSIONS?

**AXT DIMENSIONS** is an experimental AI-powered 3D world project focused on the generation, reconstruction and exploration of persistent virtual environments.

The project explores how artificial intelligence can transform different types of visual and textual input into navigable three-dimensional worlds.

AXT DIMENSIONS supports the exploration of workflows such as:

* 📝 **Text → 3D World**
* 🖼️ **Single Image → 3D World**
* 📸 **Multi-View Images → 3D Reconstruction**
* 🎥 **Video → 3D Reconstruction**
* 🌍 **Generated Scenes → Persistent 3D Environments**

Unlike traditional AI systems that generate only videos or static images, the underlying technology explored by this project focuses on persistent 3D representations that can potentially be explored, edited and integrated into compatible 3D workflows.

## 🎮 Why Persistent 3D Worlds?

Many generative AI systems produce images or videos.

While visually impressive, those outputs are fundamentally collections of pixels.

AXT DIMENSIONS explores a different direction:

> **Generate a world instead of generating a video of a world.**

Persistent 3D representations can potentially provide:

| Capability          | Traditional Video Generation | Persistent 3D Worlds          |
| ------------------- | ---------------------------- | ----------------------------- |
| Output              | Pixel-based video            | 3D representation             |
| Persistence         | Temporary sequence           | Persistent environment        |
| Navigation          | Limited                      | Spatial exploration           |
| Editing             | Difficult                    | Potentially editable          |
| Multiple viewpoints | Generated individually       | Native spatial representation |
| Game engines        | Limited                      | Potential integration         |
| Simulation          | Limited                      | Potentially supported         |
| 3D consistency      | Difficult                    | Spatially grounded            |

This opens the door to more interactive and persistent AI-generated environments.
